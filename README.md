**Short description** -
  CheckIP is a clean, easy-to-use site that provides instant insights
  into your network, device, and browser details.

**🌐 Primary Details**

Parameter	          Description
IP Address	        Your public IP address currently visible to web servers.
Country	            The geographical location and country linked to your network connection.
Operating System	  The primary operating system installed on your device.
Browser	            Your current web browser name and its precise version.

**🔻 Other Details**

Parameter	          Description
Time Zone	          The geographical time zone detected from your system configuration.
Local Time	        The current local time reported directly by your browser.
Browser Language	  The preferred language configured for web content rendering.
Device Type	        The category of hardware used to browse (e.g., Desktop, Mobile, Tablet).
Screen Resolution	  The active display dimensions of your screen measured in pixels.
Network Connection	The type or speed status of your active internet connection.
